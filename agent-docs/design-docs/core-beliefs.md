# Core Beliefs

1. Keep repository-local docs as the system of record for agent reasoning.
2. Keep AGENTS files short and route-oriented; use docs for depth.
3. Encode durable constraints as mechanically enforceable scripts and CI checks.
4. Prefer explicit event/source/schema boundaries over implicit coupling.
5. Treat execution plans and debt tracking as versioned repository artifacts.
6. Prioritize legibility for future agent runs over one-off prompt instructions.
